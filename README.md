# Patient Signals Demo — Command Center

Static mockup of the Patient Signals demo, restyled to match the Life Sciences
Cloud Command Center prototype. Five screens (Detect, Understand, Route,
Resolve, Verify) navigated via the top story tab bar.

## Hosting on GitHub Pages

1. Push this folder's contents to a GitHub repo (root of the repo, or a
   `docs/` folder — either works, you just point Pages at whichever you use).
2. In the repo, go to **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Pick the branch (e.g. `main`) and the folder (`/ (root)` or `/docs`),
   then **Save**.
5. GitHub builds the site (takes a minute or two) and gives you a URL like
   `https://<username>.github.io/<repo-name>/`.

No build step, server, or dependencies required — it's a single self-contained
`index.html`.
